# Site Analyzer

Веб-приложение на FastAPI для комплексного анализа сайтов и их протоколов.

## Возможности

- **SSL/TLS анализ** — проверка сертификата, протоколов, шифров
- **DNS записи** — A, AAAA, MX, NS, TXT, CNAME
- **HTTP заголовки** — полный список заголовков ответа
- **Оценка безопасности** — автоматический скоринг на основе заголовков безопасности
- **Определение технологий** — фреймворки, CMS, серверы
- **Производительность** — время ответа, TTFB, размер контента
- **WHOIS** — информация о домене и регистраторе
- **Сканирование портов** — проверка основных сетевых портов

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Приложение запустится на `http://localhost:8000`

## API

### POST /api/analyze

```json
{
  "url": "example.com"
}
```

Возвращает полный JSON-отчёт с результатами анализа.

### GET /api/health

Проверка состояния сервиса.
