# Анализатор сетевого траффика (Network Sniffer)

Простая программа-анализатор сетевого траффика с графическим интерфейсом, которая парсит IP, TCP, UDP и DNS пакеты и выводит все параметры проанализированных пакетов в виде древовидного списка. 

## Описание программы

В программе есть выбор доступных сетевых интерфейсов для анализа траффика на них, а также кнопка для запуска и остановки анализатора. Ниже находится список со всеми проанализированными пакетами, где можно просмотреть ip адреса отправителя и получателя пакета, протокол и все параметры заголовков. 

**Важно: для нормальной работы анализатора могут потребоваться права администратора!**
